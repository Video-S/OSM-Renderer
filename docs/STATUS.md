## Known Limitations & Incomplete Capabilities

- **Single-Threaded Geometry Synthesis**: Large OSM queries (> 5,000 ways) execute polygon clipping and triangulation on the main browser thread; background web worker offloading is not yet implemented.
- **Local Metric Projection Range**: The equirectangular projection assumes a constant meridian radius and is optimized for neighborhood tiles up to ~5 km. Continental-scale streaming is out of scope.
- **Complex Multi-Level Stack Interchanges**: Highly skewed 5+ way junctions with overlapping flyover tiers rely on OSM layer tags; incomplete source tags can lead to flat road merges.
- **E2+ Remaining Pre-Promotion Follow-Ups**: While internal provenance-split bend gaps (`provenance_split_bend_gap`) and the `0.0312 m²` pinched-ring coplanar overlap in `H01` are now resolved across all 12 benchmark datasets (`0` coverage defects and `0` positive-area overlaps), `diagnostics.featuresFullySubtracted` counter synchronization on full E2+ stroke subtraction remains open for targeted follow-up (`docs/road-rendering-roadmap.md`).

- **Large Map Loading Bottleneck Investigation (`TKT-025` — In Progress, Diagnostic-Only)**:
   - Reproduced `4 × 4 km` hangs end-to-end in headless Playwright Chromium (`production-legacy` defaults) across both frozen Hengelo scaling extracts (`S3`/`S4`/`S5`) and live `/api/osm-data` Overijssel offline queries (`r = 500 m` / `1000 m` / `2000 m`), adding non-intrusive `SceneBuildStageTimingsMs` telemetry (`GeometryBuilder.ts` $\to$ `MapLoadDiagnostics.ts` $\to$ `__M21_LAB__.getSnapshot()`).

   - Distinguished memory pressure from CPU blocking: browser V8 heap peaked at `843.02 MB` / `4,192 MB` limit on live `r = 2000 m` (retained `193.43 MB` CPU buffers + `29.39 MB` BVHs; renderer RSS `1,308.60 MB`), while coexisting intermediate data structures (`osmtogeojson` + `osmCache` on server [`545.9 -> 1,337.7 MB` peak RSS], plus client `currentRawGeoJson` + dual `mapData` + `topologySource` + `35,979` `ExtrudeGeometry` objects) amplify transient RAM pressure. Concluded continuous spatial tiling is **not** strictly required before indexing those two $O(N^2)$ legacy road loops. See `tickets/TKT-025-large-map-loading-bottleneck-investigation.md`.
